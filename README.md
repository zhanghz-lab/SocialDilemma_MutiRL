# SocialDilemma_MutiRL

This repository contains the source code for the paper "Identifying effective state representations for cooperative evolution in reinforcement learning".

## System Require

### **Operating Systems**

- **Tested on:** Windows 11

- **Hardware:** Standard desktop computer (e.g., Intel i5/i7/i9, 8GB RAM)

### **Software Dependencies**

- **Python Version:** Python 3.8.5 or higher

- **Required Python Packages:**

- numpy

- networkx

- matplotlib

- random

## **Installation Guide**

### **Clone the Repository**

`git clone https://github.com/zhanghz-lab/SocialDilemma_MutiRL.git`

### **Demo**

`python main.py`
